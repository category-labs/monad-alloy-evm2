# Monad EVM2

Monad execution on [evm2](https://github.com/alloy-rs/evm2), with blockchain
fixture replay and execution parity checks.

| Crate | Description |
| --- | --- |
| [`monad-evm2`](crates/monad-evm2/README.md) | Runtime library for Monad hardforks, gas rules, precompiles, staking, reserve balances, and inspected execution. |
| [`monad-evm2-fixtures`](crates/monad-fixtures/README.md) | Blockchain fixture runner that verifies execution commitments and compares results with monad-revm. |

Each crate's README covers usage, features, and local development.
