# Monad EVM2

Monad execution on [evm2](https://github.com/alloy-rs/evm2), with blockchain
fixture replay and browser/Node.js bindings.

| Crate | Description |
| --- | --- |
| [`monad-evm2`](crates/monad-evm2/README.md) | Runtime library for Monad hardforks, gas rules, precompiles, staking, reserve balances, and inspected execution. |
| [`monad-evm2-fixtures`](crates/monad-fixtures/README.md) | Blockchain fixture runner that verifies execution commitments and protocol outcomes. |
| [`monad-evm2js`](crates/monad-evm2js/README.md) | Browser and Node.js WASM wrapper for local execution, snapshots, and debugging. |
